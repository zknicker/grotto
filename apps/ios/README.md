# Grotto for iPhone

Native iPhone client built with Expo, React Native, Expo Router, and HeroUI Native.

From the repository root:

```bash
bun install
bun run --filter @tavern/ios ios
```

The native `ios/` project is generated by Expo and intentionally ignored. Regenerate it after native
dependency or app configuration changes with:

```bash
cd apps/ios
bunx expo prebuild --platform ios --clean
```

The app uses a native split-drawer shell inspired by leading chat apps: the chat canvas moves aside
to reveal Grotto navigation, while preserving direct access through a top-left trigger and a
horizontal swipe.
